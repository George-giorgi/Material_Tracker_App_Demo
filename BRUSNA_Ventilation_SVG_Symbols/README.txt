BRUSNA ventilation SVG symbols

12 transparent-background vector symbols for use on 2D PDF drawings.
These are generic schematic icons, not exact manufacturer drawings or scaled product geometry.
Each SVG uses a 64x64 viewBox and can be scaled/rotated without loss of quality.

Suggested placement data:
id, type, page, x, y, rotation, scale.
Keep SVG source unchanged; apply transform to the placed SVG element.
Use pointer drag to update x/y and a rotation handle or keyboard shortcut to update rotation.
Store x/y in PDF page coordinates so placements remain aligned when zooming.
